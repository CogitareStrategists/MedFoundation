
# TRICON 2026 Website

This folder is ready for GitHub Pages.

## Included files
- index.html
- tricon-2026.html
- about-foundation.html
- past-events.html
- contact.html
- styles.css
- script.js
- FINAL BROCHURE.pdf

## Deployment
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Open repository Settings > Pages.
4. Set the source to deploy from the main branch root.
5. Save and wait for publishing.

## Notes
- The brochure is bundled locally, so brochure links work without an external URL.
- Registration buttons open the Google Form directly.


# Medical & Health Care Foundation Website

This folder is ready for GitHub Pages.

## Included files
- index.html (About Foundation)
- upcoming-events.html (Upcoming Events)
- tricon.html (redirect to upcoming-events.html, kept for old links)
- past-events.html
- contact.html
- styles.css
- script.js
- ratnakar-memorial-lecture-2026.ics (Add to Calendar file for the current event)
- assets/foundation-logo.jpeg
- CNAME (medhealthcarefoundation.com)

## Deployment
1. Open repository Settings > Pages.
2. Set the source to deploy from the main branch root.
3. Save and wait for publishing.

## Notes
- Registration buttons open the Google Form directly.
- The TRICON 2026 conference page and brochure have been removed at the Foundation's request; the conference is summarised on the Past Events page.
